# Economic Clarity

**Economic Warfare 101 — Silent Leverage and Elite Incentives**

Shareable insights on the quieter forms of economic power, elite incentives, and how ordinary people experience the effects.

## Live site

Once deployed: https://economicclarity.vercel.app

## Deploy

1. Import this repository into Vercel
2. Project name: `economicclarity`
3. Deploy — it will be available at economicclarity.vercel.app

## Images

Upload the 8 series images (renamed to `ew-01.png` … `ew-08.png`) into the `/images` folder of this repository so the cards display correctly.

The images are currently in your Google Drive under the Economic Warfare 101 series titles.

## Structure

- `index.html` — Homepage with numbered shareable cards in exact order
- `article.html` — Full article page (SEO-friendly, printable, shareable)
- `images/` — Series graphics
